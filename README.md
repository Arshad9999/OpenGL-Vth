# OpenGL Graphics Labs

Fifteen C++ OpenGL/FreeGLUT lab exercises covering lines, letters, shapes, animation, and 3D objects.

## Setup

The examples target C++ with OpenGL and FreeGLUT. The original environment was Dev-C++ on Windows with linker flags:

```text
-lopengl32 -lfreeglut -lglu32
```

Build one lab at a time; each example is a separate program. Install the compiler and matching FreeGLUT development libraries first. A graphical display is required. These Windows-targeted builds have not been verified on macOS or Linux.
